# Restaurant POS (PERN)

ລະບົບຂາຍຕຳ & ອາຫານ — ສະຕ໋ອກ, ບິນ, ພິມຄົວ, ຈ່າຍເງິນ, ລາຍງານລາຍຮັບ (ເງິນສົດ / ໂອນ).

## ຕິດຕັ້ງ

1. ຄັດລອກ `.env.example` ເປັນ `server/.env` (ມີແລ້ວ = SQLite ຢູ່ `server/prisma/dev.db`)
2. ຈາກໂຟນເດີໂປຣເຈັກ:

```bash
npm install
npm run db:push
npm run db:seed
npm run dev
```

- ໜ້າຮ້ານ: http://localhost:5173  
- API: http://localhost:4000  

## ວຽກງານຫຼັກ

| ໜ້າ | ຟັງຊັນ |
|-----|--------|
| ເຄົາເມນູ / ບິນ | ສັ່ງ → ພິມຄົວ → ພ້ອມຈ່າຍ → ຈ່າຍ (ສົດ/ໂອນ) |
| ສະຕ໋ອກ | ເພີ່ມ/ແກ້ສິນຄ້າຄົງຄັງ |
| ເມນູ | ຕັ້ງລາຄາຕຳ ແລະ ອາຫານທົ່ວໄປ |
| ລາຍງານ | ລາຍຮັບຕາມວັນ ແລະ ເດືອນ |

## ຂັ້ນຕອນບິນ

1. **ບິນໃໝ່** — ເລືອກເມນູ (ສະຖານະ `DRAFT`)
2. **ພິມເມນູຄົວ** — ສົ່ງໄປຄົວ (`IN_KITCHEN`)
3. **ເຮັດສຳເລັດ — ພ້ອມຈ່າຍ** (`AWAITING_PAYMENT`)
4. **ຢືນຢັນຈ່າຍເງິນ** — ເງິນສົດ ແລະ/ຫຼື ໂອນ (`PAID`)
